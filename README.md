# The Fount of Knowledge and Wisdom: GCSE Sociology

A free revision site for AQA GCSE Sociology: flashcards, quizzes, 12-mark practice, exam skills, mock papers and arcade games, covering key concepts, theories, research methods, families, education, crime and deviance, and social stratification.

It's a single static page (`index.html`) with no build step and no accounts. Progress is saved in each student's browser.

- **Exam countdown:** add dates to `EXAMS` in `index.html`.
- **Mock-topic mode:** set `MOCK_END` in `index.html` to your mock date.
- **Parent guide:** `guide.html`.
